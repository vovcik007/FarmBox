# Участь у розробці

Створюйте короткоживучі гілки `feature/*`, `hotfix/*` або `docs/*` від `main`, виконуйте перевірки та відкривайте PR у `main`. Дочекайтеся успіху CI та незалежного review, якщо доступний інший учасник. Для демонстрації графа використовується merge commit; GitHub Flow допускає й інші способи злиття.
