# Матеріали для презентації

На слайді використайте [фактичну діаграму релізної історії](git-graph.svg). Редаговане джерело — [Graphviz DOT](git-graph.dot); для генерації встановленим Graphviz виконайте `dot -Tsvg docs/lab3/git-graph.dot -o git-graph-rendered.svg`. SVG також відкривається й редагується в Inkscape. Історичні назви гілок позначають шлях комітів, а не наявні віддалені refs; документаційна гілка після знімка до діаграми не входить.
